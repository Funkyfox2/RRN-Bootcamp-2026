# RRN-Bootcamp-2026
Welcome Coders, Mentors, and New FRC students,

This is the home page for the 2026 Rural Robotics Online Coding Bootcamp. 
Here you can find resources such as example code, presenter slideshows and links to additional online sites for learning more about coding for FRC.

Presenters: include your code as full folders labeled with the teaching topic and location and your put slideshows in the slideshow folder with the name and presenter hour.

Mentors: please share this repository with your students and help them setup before the bootcamp

Students: look at the various resources found in this repository and feel free to explore and experiment
